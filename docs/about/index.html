About this catalog

Scientific definitions documented with the catalog are provided below. Unapproved publication metadata remains marked as unconfirmed.

Overview

This catalog provides horizontal-component station-orientation correction estimates for individual seismic stations. Each row represents one interval during which a single correction is considered valid. Stations with changes in estimated orientation are represented by multiple rows.

Event-based measurement method

The corrections are estimated on an event basis. P-wave arrival angles are measured for individual cataloged earthquakes and used to estimate station orientation. The arrival-angle measurements follow the method of Tarumi & Yoshizawa (2025).

Records and validity intervals

Each estimate is valid for start_time ≤ time < end_time. Validity intervals are determined using the GCMT event catalog. Times are expressed in UTC using ISO 8601.

In the presentation catalog, times are rounded to the nearest second and orientation corrections and uncertainties to 0.1 degree. Beside each station name, the catalog displays the median orientation correction x ± standard deviation σ in degrees, followed in parentheses by the number of events used for the estimate. Use the original unrounded values for calculations when they are available. Station-level source CSVs may retain their original field names and precision.

Column definitions

The table maps the normalized catalog fields defined in README.cat to the source fields retained by the current station and network downloads. error_flag is a derived field for the normalized catalog.

Quality control and error_flag

error_flag is a screening indicator for a possible observation error; a value of 1 does not establish that an estimate is wrong. Measurements with unexpected linear trends in arrival angle against back-azimuth were screened automatically, but automatic processing may not remove all such data.

Applying the correction

Apply the correction as $cmpaz_corrected = $cmpaz + correction_deg.

Station-specific processing note

For IU.TIXI, the processing random seed was changed from 0 to 100.
