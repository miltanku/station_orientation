# Station Orientation Catalog

The Station Orientation Catalog provides event-based estimates of
horizontal-component sensor-orientation corrections for seismic stations.
Results are organized by seismic network, station, and validity interval.

## Browse the catalog

- [English catalog](docs/index.html)
- [日本語版カタログ](docs/ja/index.html)

The catalog includes station- and network-level CSV files, summary PDFs,
results without screening where available, and annual orientation maps.
Scientific definitions, quality-control notes, and citation information are
provided on the [About page](docs/about/index.html).

## Language and review status

The English-language text has been reviewed by the project maintainer. All
Japanese-language text was generated using AI and has not been human-proofread.
The Japanese version may therefore contain mistranslations or unnatural
wording; consult the English version when precise interpretation matters.

## Repository scope

This repository publishes the generated bilingual static website under
[`docs/`](docs/) for GitHub Pages. Observation inputs, local processing
scripts, notebooks, build reports, SAGE-derived metadata, and intermediate
products are maintained separately and are not included in this public
repository.

## Station Orientation Catalogについて

Station Orientation Catalogは，地震観測点の水平動成分について，イベント
ベースで推定したセンサー方位補正値を提供するカタログです．結果は，地震観測
ネットワーク，観測点および有効期間ごとに整理されています．

### カタログを閲覧する

- [英語版カタログ](docs/index.html)
- [日本語版カタログ](docs/ja/index.html)

観測点別・ネットワーク別CSV，サマリーPDF，利用可能な場合はscreeningなしの
結果，および年別方位マップを収録しています．科学的定義，品質管理上の注意，
引用情報については，[Aboutページ](docs/ja/about/index.html)を参照してください．

### 言語と校正状況

英語版の文章はプロジェクト管理者が校正しています．日本語版の文章はすべて
AIで生成されており，人による校正は行われていません．そのため，日本語版には
誤訳や不自然な表現が含まれる可能性があります．厳密な解釈が必要な場合は，
英語版を参照してください．

### リポジトリの公開範囲

このリポジトリでは，GitHub Pages用に生成された日英両言語の静的サイトを

Notebook，ビルドレポート，SAGE由来のメタデータおよび中間生成物は別に管理し，
この公開リポジトリには含めません．
